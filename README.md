# App Sistema Solar - DEVinHouse Clamed

Este repositório contém o projeto **app-sistema-solar-lppellin**, desenvolvido como parte do programa **DEVinHouse Clamed V3** em parceria com o **GitHub Classroom**.

## Descrição do Projeto

O **App Sistema Solar** é uma aplicação desenvolvida em **JavaScript** que tem como objetivo explorar e apresentar informações sobre os planetas e corpos celestes do sistema solar. Este aplicativo educacional foi projetado para ser interativo e informativo, proporcionando uma experiência de aprendizado prática e envolvente.

## Funcionalidades

- Visualização de informações detalhadas sobre os planetas do sistema solar.
- Animações interativas para navegação no sistema solar.
- Interface amigável e responsiva para diversos dispositivos.
- Uso de JavaScript puro para implementação de funcionalidades.

## Estrutura do Projeto

A estrutura do projeto está organizada da seguinte forma:

```
app-sistema-solar-lppellin/
├── index.html       # Página principal do aplicativo
├── styles/          # Arquivos de estilo CSS
├── scripts/         # Scripts JavaScript da aplicação
├── assets/          # Imagens e outros recursos estáticos
└── README.md        # Documentação do projeto
```

## Tecnologias Utilizadas

- **JavaScript**: Linguagem principal utilizada no desenvolvimento do projeto.
- **HTML5** e **CSS3**: Para estruturação e estilização da interface do aplicativo.
