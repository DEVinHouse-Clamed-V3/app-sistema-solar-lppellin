# App Sistema Solar

## Descrição do Projeto

O **App Sistema Solar** é uma aplicação desenvolvida em **React Native** que tem como objetivo explorar e apresentar informações sobre os planetas e corpos celestes do sistema solar. Este aplicativo educacional foi projetado para ser interativo e informativo, proporcionando uma experiência de aprendizado prática e envolvente.

## Funcionalidades

- Visualização de informações detalhadas sobre os planetas do sistema solar.
- Navegação interativa e fluida utilizando recursos do **React Native**.
- Interface amigável e responsiva para dispositivos móveis.
- Implementação modular e reutilizável de componentes React.

## Estrutura do Projeto

A estrutura do projeto está organizada da seguinte forma:

```
app-sistema-solar-lppellin/
├── src/                  # Código-fonte principal
│   ├── components/       # Componentes reutilizáveis
│   ├── screens/          # Telas do aplicativo
│   ├── assets/           # Imagens e outros recursos estáticos
│   └── App.js            # Arquivo principal do aplicativo
├── package.json          # Configuração do projeto e dependências
├── README.md             # Documentação do projeto
└── .gitignore            # Arquivos e pastas ignorados pelo Git
```

## Tecnologias Utilizadas

- **React Native**: Framework principal para desenvolvimento do aplicativo.
- **JavaScript**: Linguagem utilizada para implementar a lógica do aplicativo.
- **Expo**: Ferramenta para facilitar o desenvolvimento e o deploy.

## Como Executar o Projeto

1. Certifique-se de ter o **Node.js** instalado em sua máquina.

2. Instale o gerenciador de pacotes **npm** ou **yarn**.

3. Clone este repositório para sua máquina local:
   ```bash
   git clone https://github.com/DEVinHouse-Clamed-V3/app-sistema-solar-lppellin.git
   ```

4. Acesse o diretório do projeto:
   ```bash
   cd app-sistema-solar-lppellin
   ```

5. Instale as dependências do projeto:
   ```bash
   npm install
   # ou
   yarn install
   ```

6. Inicie o aplicativo:
   ```bash
   npm start
   # ou
   yarn start
   ```

7. Use um emulador ou conecte um dispositivo físico para visualizar o aplicativo.
